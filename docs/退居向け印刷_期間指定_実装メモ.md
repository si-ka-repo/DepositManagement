# 退居向け印刷：期間指定（案A）

## 概要

利用者詳細の「退居向け印刷」からモーダルで対象期間を選び、預り金明細書（退居お知らせ）を印刷する。

## UI

- 入口: 利用者詳細 → 「退居向け印刷」
- モーダル選択肢:
  - **当月のみ**: 画面の年月（現状どおり）
  - **期間を指定**: 開始日・終了日（初期値は選択中年月の月初〜月末）

## プレビュー URL

- 当月: `...&type=resident&noticeType=moveout&year=&month=`
- 期間: `...&type=resident&noticeType=moveout&startDate=&endDate=`

## API

`GET /api/print/resident-statement`

- `startDate` + `endDate` あり → `transformToResidentPrintDataForRange`（タイトルは和暦期間）
- なし → 従来の月次（退居時は和暦年月ヘッダー）
- `noticeType=moveout` で退居お知らせテンプレを適用
